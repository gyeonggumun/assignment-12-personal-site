# 문경구 · 과제 12 자기소개 포트폴리오

처음 온 사람이 3분 안에 읽고 함께 일할 이유를 발견하도록 만든 공개 자기소개 사이트입니다. 고난에서 시작해 다시 일어나고 더 나아진 지금으로 이어지는 실제 경험을 중심에 두고, 자기조절력·대인관계력·자기동기력을 날짜가 있는 장면으로 보여 줍니다.

## 공개 사이트

결과물 URL: https://gyeonggumun.github.io/assignment-12-personal-site/

React와 Vite로 구성한 정적 사이트이며, 로그인·댓글·방문자 통계를 넣지 않았습니다. GitHub Pages 배포는 `.github/workflows/deploy-pages.yml`이 `main` 푸시 때 자동으로 실행합니다.

## 파일 구조

```text
index.html                  Vite 진입 HTML
src/App.jsx                 React 앱 셸과 섹션 조합
src/components/             헤더·히어로·기록·작품·업데이터 컴포넌트
src/data.js                 공개 콘텐츠와 리추얼 기록 데이터
src/utils/records.js        CSV·마스킹 JSON 결정적 계산 로직
src/styles.css              반응형·다크 모드 디자인 시스템
self-introduction.html      자기소개서 전문 읽기 페이지
docs/                       이력서·자기소개서·경력기술서
device/                     새 기록 갱신 장치와 샘플 데이터
```

## 로컬에서 확인

Node.js 18 이상에서 다음 명령으로 실행합니다.

```text
npm install
npm run dev
```

배포 번들은 `npm run build`, 결과 확인은 `npm run preview`로 실행합니다. 첫 화면의 `오늘까지의 기록 흐름`에서 공개된 JSON 요약을 확인하고, `새 기록` 섹션에서 `예시 불러오기` 또는 파일 선택을 누른 뒤 `결과 만들기`를 선택하면 추가 입력도 브라우저 안에서 확인할 수 있습니다.

## 기록 갱신 장치 실행

Node.js 18 이상에서 다음 세 단계로 실행합니다.

```text
cd device
node update-site.js sample-records.csv output
```

생성되는 `output/last-result.json`과 `output/paragraph-candidates.md`는 같은 입력에 항상 같은 결과를 냅니다. 실제 제출 전에는 본인의 검증된 13주 기록으로 `sample-records.csv`를 교체하고, 후보 문장을 직접 검토해 승인합니다. 원문 일기나 개인정보는 저장소에 넣지 않습니다.

## AI와 나의 판단

- AI에게 맡긴 일: 문헌 구조화, 다국어 표현, 정적 웹 코드 초안과 후보 문장 계산을 도왔습니다.
- 내가 직접 판단한 일: 경험의 사실 여부, 날짜·역량 연결, 공개 범위와 지원에 사용할 문장을 결정합니다.
- 따르지 않은 제안: 실제 기록이 없는 수치를 만들거나 치료 효과를 주장하는 제안은 사용하지 않았습니다.

## 문서

`docs/`의 Markdown 파일은 지원처에 맞춰 연락 수단과 실제 13주 수치를 최종 확인한 뒤 PDF 또는 문서 파일로 변환해 제출합니다. 현재 제공된 자기소개서에는 공개 가능한 연락 수단이 없으므로 사이트에 교체 안내를 남겼습니다.
