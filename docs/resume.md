# 이력서 · 문경구

> 공개용 연락 수단과 프로젝트 기간은 제출 전 실제 정보에 맞춰 최종 입력합니다.

## 한 줄 소개

문제를 작게 나누고, 먼저 손을 내밀며, 팀과 함께 끝까지 완주하는 사람입니다.

## 핵심 역량

- 자기조절력: 계획·실행·회고를 연결하고, 복잡한 문제를 작은 단위로 나누어 검증합니다.
- 대인관계력: 질문과 인계를 구조화하고, 로그·데이터·기대값을 함께 보며 설명합니다.
- 자기동기력: 일회성 결과물에 그치지 않고 기록·문서·도구를 계속 개선합니다.

## 기술 스택

React · React 19 · Vite · JavaScript · Next.js · Supabase · WebAuthn · Node.js · CSS · 반응형 UI
