# 경력기술서 · 문경구

> 프로젝트 기간과 본인의 역할은 제출 전 실제 기록에 맞춰 최종 확인합니다.

## 1. 과제 12 · 자기소개 포트폴리오 및 기록 갱신 장치 — 자기동기력

- 상황: 지원에 사용할 자기소개를 일회성 문서가 아니라 계속 갱신되는 공개 결과물로 만들 필요가 있었습니다.
- 행동: React와 Vite로 자기소개·날짜별 기록·대표작·문서 다운로드를 구성하고, 마스킹된 CSV·JSON을 받아 기록 지표와 문단 후보를 같은 입력에 같은 결과로 생성하는 갱신 장치를 제작했습니다. 공개 범위와 타인의 실명·원문 제외 기준도 함께 정리했습니다.
- 결과: 로그인 없이 접근 가능한 포트폴리오 사이트와 재현 가능한 기록 관리 구조를 구축했습니다. 공개용 24일 리추얼 기록을 요약해 완료 23일·진행 중 1일을 출처와 함께 표시했습니다.

## 2. 과제 6 · PDS Enterprise Secure Planner — 자기조절력

- 상황: 계획과 실행을 따로 기록하지 않고, 실제 작업 결과를 다음 계획에 반영하는 개인 플래너가 필요했습니다.
- 행동: React와 Vite, Supabase를 활용해 인증·세션·RLS 기반 데이터 접근을 구성하고, Plan·Do·See 흐름에 목표·세부 과제·진행률·실행 시간·시간 오차 분석을 연결했습니다. 회고 내용을 다음 주기 계획에 반영하고 백업·복원과 중복 처리 방지 로직도 구현했습니다.
- 결과: 계획·실행·회고가 다음 계획으로 이어지는 데이터 기반 피드백 루프를 구축했습니다.

## 3. 프론트엔드 포트폴리오 웹 애플리케이션 — 자기동기력

- 상황: 정적인 포트폴리오만으로는 보안 인프라 프로젝트와 프론트엔드 구현 역량을 함께 보여주기 어려웠습니다.
- 행동: React 19와 Vite를 기반으로 상태 기반 프로젝트 상세 화면, 부드러운 탐색, 반응형 레이아웃을 구현하고 WebAuthn Passkey 인증, 키보드 접근성, 포커스 피드백을 적용했습니다.
- 결과: 보안·인프라 사례를 인터랙티브하게 탐색할 수 있는 개인 포트폴리오 웹 애플리케이션을 완성했습니다.

## 4. 과제 3 · 이미지 편집 웹 애플리케이션 — 자기동기력

- 상황: 브라우저 안에서 다양한 화면 비율과 편집 요소를 다루고 결과물을 바로 내보낼 수 있는 이미지 제작 흐름이 필요했습니다.
- 행동: 배경 이미지, 1:1·4:5·9:16 화면 비율, 도형·텍스트·에셋 레이어, 템플릿 보관함과 가져오기·내보내기 흐름을 구성했습니다. 웹용 PNG와 인쇄용 PDF 다운로드 경로도 제공했습니다.
- 결과: SNS와 인쇄 작업에 활용할 수 있는 이미지 편집 및 결과물 출력 인터페이스를 구축했습니다.

## 5. 과제 5 · AI 작업 인계 체크리스트 — 대인관계력

- 상황: AI 도구가 바뀌어도 현재 상태와 남은 작업을 잃지 않고 이어갈 수 있는 인계 기준이 필요했습니다.
- 행동: 현재 완료 지점·남은 작업·수정 금지 범위·다음 행동을 인계 문서로 구조화하고, 정상·오류·회귀를 포함한 고정 검사 10개와 관찰 가능한 기대값을 정의했습니다. 서로 다른 AI 도구의 작업 결과를 동일한 기준으로 비교했습니다.
- 결과: 저장소와 인계 문서만으로 작업 상태를 공유하고, 도구가 바뀐 뒤에도 완료 여부를 검사할 수 있는 협업 기준을 마련했습니다.

## 6. 긍정적 회고와 다음 날 자기효능감 연구 프로젝트 — 자기조절력

- 상황: 긍정적 회고와 다음 날 자기효능감의 관계를 과장 없이 검토할 수 있는 연구 문서가 필요했습니다.
- 행동: 선행연구를 바탕으로 연구 질문, 14일 단일집단 반복측정 설계, 측정도구, 데이터 관리, 혼합모형 분석계획, 참여자 보호 원칙을 정리해 한국어·영어 웹 논문으로 구현했습니다.
- 결과: 실제 연구 결과를 주장하지 않고, 재현 가능한 연구 프로토콜과 향후 저위험 자기기록 앱으로 전환하기 위한 요건을 제시했습니다.
