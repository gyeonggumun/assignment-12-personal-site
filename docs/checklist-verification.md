# 과제 12 짧은 확인 방법

1. 공개 URL을 새 시크릿 창에서 열고 계정 생성·로그인·CAPTCHA 없이 첫 화면이 보이는지 확인합니다.
2. `이야기`에서 2026년 5월의 고난 장면부터 8월 24일의 현재까지 이어지는지, 자기조절력·대인관계력·자기동기력 태그가 보이는지 확인합니다.
3. `기록`에서 오늘 기준 공개 요약(24일·완료 23일·진행 중 1일·96%)과 날짜별 하이라이트를 확인합니다. 이어 `새 기록`에서 검증된 CSV 또는 마스킹된 리추얼 JSON을 넣고 결과를 만듭니다. 같은 파일을 두 번 실행해 결과가 같은지 비교합니다. JSON은 리추얼 완료율만 계산하며 출석·제출 수치는 입력하지 않습니다.
4. `대표작`에서 논문 링크가 로그인 없이 열리는지 확인하고, 앱은 “제작 예정” 자리로 남아 있는지 확인합니다.
5. `문서`에서 이력서·자기소개서·경력기술서가 다운로드되는지 확인합니다. 공개용 연락 수단과 실제 13주 수치는 제출 전에 교체합니다.
6. `device/README.md`에 따라 새 폴더에서 `node update-site.js <기록파일> output`을 실행하고 결과 두 파일이 생성되는지 확인합니다.

## AI와 작성자의 판단

- AI에게 맡긴 일: 문헌 구조화, 다국어 표현, 정적 웹 코드 초안과 후보 문장 계산.
- 작성자가 직접 판단한 일: 경험의 사실 여부, 날짜·역량 연결, 공개 범위와 지원 문장.
- 따르지 않은 제안: 실제 기록이 없는 수치를 만들거나 치료 효과를 주장하는 제안.
