# 과제 12 제출 확인 문서

결과물 URL: https://assignment-12-personal-site-gyeonggumuns-projects.vercel.app/

이 문서는 제출 직전에 사이트와 문서가 체크리스트에 맞는지 확인하기 위한 안내서입니다. ZIP 파일은 별도로 묶어 제출합니다.

## 무엇을 하나요 (3단계 이내)

1. 결과물 URL을 새 시크릿 창에서 열고 계정 생성·로그인·인증·CAPTCHA 없이 첫 화면이 보이는지 확인합니다. `이야기`에서 고난 장면, 회복 과정, 현재의 변화와 세 역량의 날짜 태그를 확인합니다.
2. `기록`과 `오늘까지의 기록 흐름`에서 공개 데이터의 기간·완료율·출처를 확인합니다. `새 기록`에서 검증된 13주 CSV 또는 동료 이름이 마스킹된 리추얼 JSON을 넣고 결과를 만든 뒤, 같은 입력을 두 번 실행해 결과가 같은지 비교합니다.
3. `대표작`의 논문 링크, 앱 예정 자리, `문서`의 세 PDF 다운로드를 확인하고 `device/README.md`에 따라 새 폴더에서 갱신 장치를 실행합니다.

## 무엇이 보이면 통과인가요

- 첫 화면에 본인 이름과 `…한 사람`으로 끝나는 한 줄 소개가 보입니다.
- `이야기`가 고난에서 시작해 다시 일어난 장면과 현재의 변화로 이어지고, 자기조절력·대인관계력·자기동기력에 날짜가 붙어 있습니다.
- 기록 숫자는 실제 원자료와 일치하고, `내 출석 기록`, `내 리추얼 기록`, `내 제출 현황` 중 해당 출처가 표시됩니다. 출처가 없는 숫자는 입력 대기로 둡니다.
- 대표작에서 논문이 로그인 없이 열리고, 앱은 `제작 예정` 자리로 남아 있습니다.
- 이력서·자기소개서·경력기술서 PDF가 각각 다운로드됩니다.
- `device/` 실행 후 `output/last-result.json`과 `output/paragraph-candidates.md`가 생성되고 같은 입력에서 두 결과가 같습니다.
- AI가 작성한 후보는 자동 승인되지 않고, 날짜·근거·공개 범위를 작성자가 검토합니다.

## 안될 때 확인할 부분

- 수치가 서로 다르면 `src/data.js`의 공개 리추얼 기록과 실제 검증 CSV를 비교해 하나의 원자료만 사용합니다.
- `입력 대기`가 보이면 출석·제출 수치를 임의로 만들지 말고 검증된 13주 CSV를 준비합니다.
- 장치 실행 시 `require is not defined`가 나오면 `device/package.json`의 `type: commonjs`가 포함되었는지 확인합니다.
- PDF가 열리지 않으면 Vercel 배포가 최신 커밋인지 확인하고 `/docs/*.pdf` 주소를 새 시크릿 창에서 다시 엽니다.
- 로그인 또는 CAPTCHA가 나타나는 URL은 제출 URL에서 제외하거나 공개 접근 설정을 다시 확인합니다.

## AI와 나의 판단 3줄

- AI에게 맡긴 일: 문헌 구조화, 다국어 표현, 정적 웹 코드 초안과 후보 문장 계산.
- 내가 직접 판단한 일: 경험의 사실 여부, 날짜·역량 연결, 공개 범위와 지원 문장을 결정했습니다.
- 따르지 않은 제안: 실제 기록이 없는 수치를 만들거나 치료 효과를 주장하는 제안은 사용하지 않았습니다.

## 캡처해야 할 부분

1. 첫 화면: 이름, 한 줄 소개, 핵심 역량과 공개 URL이 함께 보이도록 캡처합니다.
2. 이야기: 2026년 5월·8월 12일·8월 20일 장면과 세 역량 태그가 보이도록 캡처합니다.
3. 기록: 기록 기간·완료율·출처가 보이도록 캡처합니다. 13주 수치를 반영한 뒤에는 출석·리추얼·제출 출처가 모두 보이는 화면을 캡처합니다.
4. 대표작: 논문 링크가 보이고 앱이 `제작 예정`으로 표시된 화면을 캡처합니다.
5. 문서·새 기록: 세 PDF 링크와 CSV 결과 생성 화면, 동일 결과 확인 화면을 캡처합니다.
6. 장치 실행: 새 폴더에서 실행한 명령과 `last-result.json`, `paragraph-candidates.md` 생성 결과를 캡처합니다.

## 제출 파일 구성

- 결과물 URL: 위 Vercel 주소 1개
- 문서: 이력서 PDF, 자기소개서 PDF, 경력기술서 PDF
- 장치 ZIP: `device/` 실행 소스, `README.md`, 마지막 결과 두 파일
